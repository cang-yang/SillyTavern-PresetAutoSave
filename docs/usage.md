# 使用说明

## 先认识一下界面

装好插件后，你会发现界面上多了几个东西：

- **🕐 时钟图标**（预设栏右边）：点它打开历史面板，这是插件的主界面
- **小圆点**（预设名旁边）：实时显示保存状态
- **预设下拉列表**：同系列的多个版本被合并成了一个系列名

历史面板里有三个 Tab：**记录**（看快照）、**日志**（看运行日志）、**设置**（调配置）。

---

## 预设接管（下拉列表合并）

### 是啥意思

你有没有遇到过下拉列表里一堆 `星辰旅人 V1`、`星辰旅人 V2`、`星辰旅人 V3 Final`……看着头疼？

开启预设接管后，这些同系列的版本会自动合并成一个「星辰旅人」，下拉列表瞬间清爽。

选中「星辰旅人」时默认应用最新版本（V3 Final）。

### 想指定用哪个版本？

1. 打开 🕐 历史面板
2. 找到那个系列 → 展开
3. 在想要的版本卡上点 📌 图钉
4. 搞定，以后选这个系列就固定用这个版本了

### 想直接切到某个版本？

在版本卡上点 ✓ 就行。

### 不想用这个功能？

历史面板 → 设置 → 预设接管 → 关掉开关。下拉列表立刻恢复原样。

### 分组识别很聪明

插件能识别各种版本号格式：`V1`、`v2.0`、`Alpha`、`Beta`、`RC1`、日期格式 `0425`、中文数字、罗马数字……基本上你能想到的格式都认得。

如果某个预设被误分组了，可以去 设置 → 预设分组 → 管理分组 → 手动调整。

## 自动保存

### 基本逻辑

修改属于预设的生成参数或提示词内容后，插件会等你停下来再自动保存。模型连接、凭据和运行时状态不属于历史内容，单独改变这些设置不会生成有意义的预设历史。

- 普通操作等 800ms，文本输入等 1.5s（怕你还没打完字就保存了）
- 拖滑块的时候不保存，松手了才保存
- 内容没变的话不会多余保存

这些延迟时间都可以在设置里调。

### 小圆点颜色含义

| 颜色 | 意思 |
|------|------|
| ⚫ 灰 | 啥事没有 |
| 🟡 黄 | 检测到修改了，等一下就保存 |
| 🔵 蓝 | 正在保存中 |
| 🟢 绿 | 已提交成功，后续编辑会更新状态 |
| 🔴 红 | 保存出错，错误不会被计时器自动清除 |

状态文字是判断依据，不能只看颜色。“预设已保存，历史记录未完成”表示部分完成，需要检查历史存储错误。

### 切换保护

切到别的预设之前，插件会自动把当前的修改备份一份。就算你改了半天忘了保存直接切走了，也不会丢东西。

默认开着的，不想要可以在设置里关。

## 历史快照

### 怎么看

点 🕐 打开历史面板，切到「记录」Tab。

快照按 **系列 → 版本 → 快照** 三级组织。每条快照显示时间、来源（auto=自动保存、manual=手动）、大小。

也可以切成「平铺视图」，所有快照按时间排列，方便看最近都改了啥。

### 能做什么

**每条快照可以：**
- ↩ **恢复**：回到这个时间点的状态（会让你确认一下）
- 👁 **查看**：看这条快照的完整数据
- 📌 **钉选**：标记重要节点，不会被自动清理掉
- ✏ **重命名**：起个好认的名字，比如「调温度之前的备份」
- 🅰🅱 **标记对比**：选两个快照来 diff
- 🗑 **删除**：不要了就删

**每个版本可以：**
- 📌 **设为默认**：让这个系列固定用这个版本
- ✓ **直接应用**：立刻切到这个版本

### 搜索和筛选

面板顶部可以筛选全部、当前预设、已锁定、今天或本周，也可以搜索预设名。

## 快照对比

想看两次修改之间到底改了什么？

1. 在一条快照上点 🅰（标记为 A）
2. 在另一条上点 🅱（标记为 B）
3. 点面板顶部的「开始对比」

对比界面会分三个维度展示差异：

- **参数差异**：温度、top_p 这些数值参数的变化
- **Prompt 差异**：提示词文本的逐行对比
- **排序差异**：Prompt 顺序有没有变

## 导入导出

### 导出快照

历史面板 → 设置 → 「导出全部」→ 会下载一个 JSON 文件。

导出会过滤已识别的连接配置和凭据字段，但不会改写提示词正文。正文或自定义扩展数据中可能含有你主动填写的私密信息；对外分享前仍应检查导出内容。

### 导入快照

历史面板 → 设置 → 「导入」→ 选 JSON 文件。

导入的时候可以选「合并」（保留已有数据，把新的加进来）或「替换」（清空已有，用导入的数据覆盖）。一般选合并就行。

### 跨设备迁移

设备 A 导出 → 文件拷过去 → 设备 B 导入（合并模式）。就这么简单。

## 设置说明

所有设置在 **🕐 历史面板 → 设置 Tab**。

默认配置对大多数人来说都够用了。如果你想调，这里简单说一下：

**自动保存相关：**
- 通用防抖延迟（默认 800ms）— 调大一点可以减少保存频率
- 文本框防抖延迟（默认 1500ms）— 打字多的话可以调大点
- 滑块释放保存（默认开）— 建议别关
- 跳过未变化的保存（默认开）— 建议别关

**历史记录相关：**
- 每预设保留条数（默认 50 条）— 存储空间紧张可以调小
- 合并窗口（默认 30 秒）— 这段时间内的连续修改只算一条快照
- 历史数量限制用于控制普通快照增长；置顶记录和未验证的恢复数据受到保护。浏览器实际配额取决于环境，遇到空间不足应先导出备份再清理。

**其他：**
- 切换保护 — 建议保持开启
- 预设接管 — 不喜欢就关了
- 调试日志 — 遇到问题时开着方便排查

## 常见问题

**Q: 预设下拉显示不对了？**
> 设置里关掉预设接管就恢复了。

**Q: 选了系列但用的版本不对？**
> 去历史面板里找到那个系列，在想要的版本上点📌设为默认。

**Q: 不想让某个预设被合并？**
> 打开分组管理，将它移入单独的系列。显示别名与手动分组不会改变原预设名称或历史归属。

**Q: 数据存哪了？会丢吗？**
> 存在浏览器的 IndexedDB 里。清浏览器数据就没了。建议偶尔「导出全部」备份一下。

**Q: 性能有问题吗？**
> 列表使用摘要缓存和有界渲染。测试覆盖 500 条快照；更大历史、首次旧库迁移和很长的文本比较仍受设备与浏览器影响，不能保证所有数据规模都没有延迟。

**Q: 会动我的原始预设吗？**
> 会。自动保存、立即保存和恢复都通过酒馆预设管理器写入原预设。分组与别名只改变显示。删除扩展前请先导出历史，禁用并确认恢复完成；不要直接删除目录来跳过恢复流程。

**Q: 摘要里为什么有“其他设置”和“技术详情”？**
> 摘要优先显示可读的条目和参数名称。尚无友好标签的有效字段仍会记录，可展开技术详情查看原始字段路径；收起详情不影响快照、导出或恢复。

**Q: “预设已保存，历史记录未完成”是什么意思？**
> 酒馆预设写入已完成，但后续历史提交失败。这不是全部成功；保留现有快照并检查存储错误。恢复操作不会自动反复重写，以免覆盖后续编辑。

**Q: “检查记录”会删除快照吗？**
> 不会。它检查存疑内容并报告数量，字段较少不再被当作损坏的依据。全部原记录均保留，删除单条快照仍需明确操作和确认。

**Q: 调试的时候怎么看更多信息？**
> F12 控制台输入 `window.__pas` 可以看插件运行时信息，`window.__pas.logger.exportText()` 可以导出日志。
