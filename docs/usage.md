## 一、预设接管 ⭐（核心特性）

### 它做了什么？

把原生预设下拉列表里**同系列的多个版本自动合并成一个"系列名"**。
例如：`梦境思客V1-0425` `梦境思客V2-0426` `梦境思客V2-0427-3` 三个预设，在原生下拉里只显示一个 `梦境思客`。

### 怎么用？

#### 1. 默认行为
- 加载插件后自动启动接管
- 选中"梦境思客" → 自动应用其下**最新版本**（V2-0427-3）

#### 2. 指定每个系列的默认版本
1. 点击预设栏右侧的 🕐 图标，打开历史面板
2. 切换到「列表」Tab
3. 找到目标系列（一级）→ 展开 → 找到想设为默认的版本（二级）
4. 点击二级版本卡右侧的图钉按钮 📌
5. 该版本被标"默认 ★"
6. 之后只要你在原生下拉选择此系列，就会自动应用这个版本

#### 3. 直接应用某个具体版本
- 在二级版本卡右侧点击圆勾按钮 ✓
- 立即切换到这个具体版本（绕过代表项重定向）

#### 4. 关闭接管
- 历史面板 → 设置 Tab → 预设接管 → 关闭"接管原生预设下拉"
- 下拉**立即**恢复原状

### 系列识别规则

接管会根据预设名末尾的版本号自动归类：

| 输入 | 识别系列 | 识别版本 |
|------|---------|---------|
| `【DarkSide-小猫之神】v1.1` | `【DarkSide-小猫之神】` | `v1.1` |
| `北棱预设2.4` | `北棱预设` | `2.4` |
| `梦境思客V1-0425` | `梦境思客` | `V1-0425` |
| `梦境思客V2-0427-3` | `梦境思客` | `V2-0427-3` |
| `神秘预设v1.2` | `神秘预设` | `v1.2` |
| `夏瑾 双鱼座 Beta 0.15` | `夏瑾 双鱼座` | `Beta 0.15` |
| `Izumi 0318` | `Izumi` | `0318` |
| `Default` | `Default` | （无版本） |

### 手动覆盖归属

如果某个预设被误归（或你想把它归到另一个系列）：
1. 历史面板 → 设置 Tab → 预设分组 → 点击"管理分组"
2. 在弹出窗口里为该预设手动指定系列名（或勾选"不分组"）
3. 保存

## 二、自动保存

### 它做了什么？

修改预设的**任何参数**（滑块、复选框、文本框、Prompt、模型、温度...），停止操作 800ms 后自动保存到磁盘 + 创建一条历史快照。

### 状态指示器

预设名旁边会出现一个小圆点：

| 颜色 | 含义 |
|------|------|
| ⚫ 灰色 | 空闲，无未保存修改 |
| 🟡 黄色 | 等待保存中（防抖期） |
| 🔵 蓝色 | 正在保存 |
| 🟢 绿色 | 保存成功（2秒后变灰） |
| 🔴 红色 | 保存失败（4秒后变灰） |

### 切换保护

切换到其他预设之前，**自动备份当前未保存的修改**。即使你忘了点保存就切走，也不会丢失。

## 三、历史记录

### 三级展示

```
┌── 一级（系列）：梦境思客 · 5 个版本 · 23 条快照 · 156 KB
│   ├── 二级（版本）：V2-0427-3 · 12 条快照 · 默认 ★
│   │   ├── 三级（快照）：2025-04-29 14:32 · auto · 2.3 KB
│   │   ├── 三级（快照）：2025-04-29 13:11 · manual · 2.4 KB · 📌
│   │   └── ...
│   ├── 二级（版本）：V2-0426 · 8 条快照
│   └── 二级（版本）：V1-0425 · 3 条快照
```

### 卡片操作

每条快照右侧的按钮：
- ↩ **恢复** - 恢复到此版本（二次确认）
- 👁 **查看** - 查看完整预设 JSON
- 📌 **钉选** - 永不被自动清理
- ✏ **重命名** - 给重要节点起名字
- 🅰 **设为对比 A**
- 🅱 **设为对比 B**
- 🗑 **删除**

### 对比两个快照

1. 在两条快照上分别点 🅰 和 🅱
2. 顶部显示对比栏 → 点"开始对比"
3. 弹出 diff 视图：左侧 A · 右侧 B · 不同字段高亮 · prompt 顺序变化也会提示

### 筛选与搜索

- **筛选器**：全部 · 当前预设 · 今天 · 昨天 · 本周 · 更早
- **搜索框**：按预设名 / 系列名 / 版本号实时过滤
- **视图切换**：系列视图（默认）↔ 扁平视图

## 四、高级配置

打开历史面板 → 设置 Tab：

### 自动保存
- **总开关** —— 临时关闭自动保存（不影响接管）
- **通用防抖延迟** —— 默认 800ms，可调 100-10000ms
- **文本框防抖延迟** —— 默认 1500ms，避免输入时频繁保存
- **滑块释放保存** —— 拖动时不保存，松手才保存
- **跳过未变化的保存** —— 内容相同则不写入磁盘

### 历史记录
- **每预设保留条数** —— 默认 50，超出后删除最旧
- **合并窗口** —— 默认 30s，此时间内的连续修改合并为一条
- **存储阈值** —— 默认 50 MB，超过提示清理

### 保护
- **切换保护** —— 切换前自动备份

### 外观
- **状态指示器** —— 显示预设名旁的小圆点
- **保存时弹出通知** —— 每次保存显示 Toast（频繁保存建议关）

### 预设分组
- **启用预设系列分组** —— 三级面板的总开关
- **导入新预设时确认归属** —— 检测到新预设时弹窗
- **默认展开策略** —— 进入面板时哪些系列默认展开（仅当前 / 全部 / 全部折叠）

### 预设接管 ⭐
- **接管原生预设下拉** —— 总开关
- **代表版本策略** —— 没指定默认时的回退（最新版 / 仅手动）

### 高级
- **调试日志** —— 控制台输出详细日志（日志面板始终记录所有级别）
- **兜底轮询** —— 仅当事件触发不可靠时启用

### 危险操作
- **导出全部** —— 一键导出所有快照到 JSON
- **导入** —— 从 JSON 文件恢复（合并 / 替换两种模式）
- **清理孤立快照** —— 清理预设已删除但快照还在的孤儿数据
- **清空所有历史** —— 不可逆操作

## 五、最佳实践

### 推荐设置
| 场景 | 建议 |
|------|------|
| 重要修改前 | 在历史面板点"立即快照" → 显式备份一次 |
| 频繁微调试错 | 把通用防抖调到 1500ms 减少快照数量 |
| 多预设切换 | 保持"切换保护"开启 |
| 存储吃紧 | 进入设置降低"每预设保留条数" 或 点"清空所有历史" |
| 想试某个版本但不确定要不要切回 | 先在面板里设为对比 A，再切其它版本，随时点"恢复 A" |

### 与原生数据的关系

**重要：插件永远不修改 SillyTavern 的原生预设数据。**

- 接管只是 DOM 视觉合并 → 关闭接管立即还原
- 历史快照独立存储在 IndexedDB → 与 SillyTavern 无关
- 删除插件不会丢失任何预设

## 七、常见问题

### Q1: 我的预设下拉变奇怪了，怎么办？
A: 历史面板 → 设置 → 预设接管 → 关闭"接管原生预设下拉"。下拉立即恢复原状。

### Q2: 接管后选中"梦境思客"应用的版本不对？
A: 在历史面板二级版本卡上点击图钉，**显式指定**该系列的默认版本。

### Q3: 某些预设我不想被合并？
A: 历史面板 → 设置 → 预设分组 → 管理分组 → 给该预设勾选"不分组"。

### Q4: 数据存储在哪里？
A: 浏览器 IndexedDB（`pas_history` 数据库）。删除浏览器数据 = 全部丢失，建议定期"导出全部"备份。

### Q5: 在两个不同设备使用如何同步？
A: 设备 A "导出全部" → 复制 JSON 到设备 B → "导入"（合并模式）。

### Q6: 性能会不会有问题？
A: 不会。本插件做了大量优化：`content-visibility: auto`、`requestAnimationFrame` 批渲染、Promise.all 并行 IO、原地切换 DOM、LRU 缓存（解析预设名 0.06us 缓存命中）。即使有 5000+ 条快照也流畅。
