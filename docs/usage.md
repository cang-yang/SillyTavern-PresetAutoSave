# 使用指南

## 基础使用

### 自动保存

安装后**完全无需操作**！修改预设的任何参数（滑块、复选框、文本框、Prompt等），都会在你停止操作 800ms 后自动保存。

### 状态指示器

预设名旁边会出现一个小圆点：

| 颜色 | 含义 |
|------|------|
| ⚫ 灰色 | 空闲，无未保存修改 |
| 🟡 黄色 | 等待保存中（防抖期） |
| 🔵 蓝色 | 正在保存 |
| 🟢 绿色 | 保存成功 |
| 🔴 红色 | 保存失败 |

### 历史记录

点击预设栏最右边的 🕐 时钟图标，打开历史记录面板：

- **筛选器**：按「全部」「当前预设」「今天」「本周」筛选
- **搜索框**：按预设名快速查找
- **卡片操作**：
  - ↩ **恢复** - 恢复到此版本（需二次确认）
  - 👁 **查看** - 查看完整预设JSON
  - 🗑 **删除** - 删除此条记录

## 高级配置

打开历史面板 → 切换到「设置」标签：

### 自动保存
- **总开关**：临时关闭自动保存
- **防抖延迟**：修改后多久触发保存（建议 500-1500ms）

### 历史管理
- **每预设保留条数**：超出后自动删除最旧记录
- **存储清理**：手动清理超过设定大小的旧记录

### 切换保护
启用后，切换到其他预设前会**自动备份当前预设**，即使忘记保存也不会丢失。

### 通知与提示
- **状态指示器**：是否显示预设名旁的小圆点
- **保存提示**：每次保存是否显示Toast（频繁保存时建议关闭）

## 最佳实践

1. **重要修改前** → 手动备份一次（也可关闭自动保存）
2. **频繁试错** → 提高防抖到 1500ms 减少存储压力
3. **多预设切换** → 保持「切换保护」开启
4. **存储满了** → 进入设置「清空所有历史」或调低保留条数
