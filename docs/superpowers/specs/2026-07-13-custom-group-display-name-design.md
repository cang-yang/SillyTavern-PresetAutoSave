# 自定义分组显示名称设计

## 目标

允许用户为自动识别或手动创建的预设分组设置更符合自己习惯的显示名称。操作体验应接近给文件夹改名：直接、安静、可撤销，不弹出打断上下文的输入窗口。

该功能只改变分组的显示名称，不修改 SillyTavern 中真实的预设名称，也不改变预设的分组归属。

## 成功标准

- 用户可以在“管理分组”窗口中直接编辑分组名称。
- 桌面端和移动端都能发现并完成改名操作。
- 新加入同一自动识别系列的预设自动沿用自定义名称。
- 历史列表、分组管理器和预设接管下拉使用同一个解析结果。
- 改名不破坏手动归属、嵌套关系、默认版本或历史数据。
- 用户可以无确认地恢复自动识别名称。

## 交互设计

### 进入编辑

- 分组标题旁提供铅笔按钮。
- 桌面端按钮在分组标题悬停或键盘聚焦时清晰显现，静止状态保持低视觉权重。
- 触屏端按钮始终可见，点击区域不小于 44px。
- 三点菜单继续提供“重命名分组”，作为一致且可发现的第二入口。
- 不使用双击或长按，避免与分组展开、拖拽和移动端手势冲突。

### 编辑过程

- 名称在原位置切换为单行输入框，不打开 Popup 或浏览器 prompt。
- 输入框自动聚焦并选中当前显示名称。
- Enter 保存；Escape 放弃并恢复原显示名称。
- 中文输入法处于 composition 状态时，Enter 不触发保存。
- 点击编辑区域外部时，有效名称自动保存；无效名称保持编辑并显示就地错误。
- 保存成功只更新界面，不显示成功 Toast。

### 校验

- 保存前移除首尾空白，保留内部空格、中文、英文和 Emoji。
- 空名称不允许保存。
- 名称最长 120 个 Unicode 字符；超长时提示，不静默截断。
- 解析后的显示名称不得与其他分组显示名称重复，比较时忽略大小写、全半角和首尾空白。
- 与当前显示名称相同则退出编辑，不写入设置。
- 错误紧邻输入框显示，并通过 `aria-describedby` 与输入框关联。

### 恢复自动名称

- 已设置别名的分组三点菜单显示“恢复自动名称「原名称」”。
- 该操作立即执行，不要求确认，因为不删除数据且随时可以重新设置。
- 分组标题不显示额外“自定义”徽标，避免视觉噪音。
- 标题可通过 tooltip/accessible description 暴露原自动名称。

## 数据模型

新增设置字段：

```js
groupingSeriesAliases: {
  [canonicalSeriesKey]: displayName
}
```

`canonicalSeriesKey` 是自动识别或手动分组的稳定归一化键；`displayName` 是用户输入的名称。设置模块使用与现有字符串映射一致的防御性校验，并额外执行显示名称长度限制。

别名不写入 `groupingManualOverrides`。后者继续只表达“某个预设被手动移动到哪个分组”，避免将“改名”和“改变归属”混为一谈。

## 分组解析边界

分组流程分为两个概念：

1. canonical series：负责成员归属、嵌套树、默认版本和稳定身份。
2. display series：在所有面向用户的界面中展示，优先使用别名。

核心分组函数输出稳定键、自动名称和最终显示名称。调用方不得自行拼接或覆盖名称。

嵌套树、`seriesDefaultApply` 和拖拽数据继续使用 canonical key。这样改名不会改变结构或让默认版本失效。

## 组件改动

### settings.js

- 增加 `groupingSeriesAliases` 默认值和校验器。
- 保持旧用户设置零迁移兼容。

### preset-grouping.js

- 增加纯函数来解析和校验别名。
- 分组结果同时携带 `canonicalKey`、`automaticName` 和 `displayName`。
- 对现有只读取 `series` 的调用保持兼容，`series` 代表最终显示名称。

### panel-group-manager.js

- 增加内联编辑状态和渲染。
- 增加保存、取消、恢复自动名称操作。
- 刷新局部界面后恢复合理焦点。
- 保持拖拽、展开和菜单点击互不干扰。

### 其他消费者

- 历史列表、接管下拉、分组摘要和移动目标选择统一传入别名映射。
- 设置重置同时清空别名。
- 导入导出沿用现有 extension settings 行为，不改变历史备份格式。

### i18n 与样式

- 添加中英文的编辑、恢复和校验文案。
- 内联输入框沿用现有面板 token，保证明暗主题、焦点可见性和移动端触控尺寸。
- 动效只用于名称与输入框的轻微过渡，并遵守 `prefers-reduced-motion`。

## 错误处理

- 设置写入失败时保留编辑内容并显示就地错误，不伪装成保存成功。
- 发现旧配置中的无效别名时忽略该项并使用自动名称。
- 别名目标不存在时保留设置，以便暂时缺失的预设重新出现后恢复用户名称。
- 两个旧别名发生冲突时不合并分组；界面使用自动名称回退并允许用户重新编辑。

## 测试策略

### 纯函数

- 有别名和无别名时的分组结果。
- 新版本加入后继承相同 canonical key 的别名。
- 空白、大小写、全半角和重复名称判断。
- 别名不改变成员归属、版本解析和代表版本选择。

### 管理界面

- 铅笔按钮和菜单都能进入编辑。
- Enter、Escape、失焦和 IME composition 行为。
- 无效名称显示就地错误且不写设置。
- 保存和恢复后焦点位置合理。
- 移动端按钮具备足够触控尺寸。

### 集成回归

- 历史列表、分组管理器和接管下拉显示一致。
- 嵌套分组、拖拽、默认版本和手动覆盖在改名前后保持稳定。
- 现有导入、设置重置和 i18n 完整性检查继续通过。

## 非目标

- 不修改真实预设文件名。
- 不提供批量别名编辑或颜色、图标等分组装饰。
- 不引入新的弹窗框架或 UI 依赖。
- 不把分组显示别名扩展为任意层级的独立实体系统。
