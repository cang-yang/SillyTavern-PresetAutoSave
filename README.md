# SillyTavern Preset Auto Save

一个 SillyTavern 的预设管理插件。帮你自动保存预设、合并下拉列表里的版本号、改坏了还能回滚。

---

## 这玩意能干嘛

- **自动保存**：改了预设参数会自动帮你存，不用再手动点保存了
- **预设接管**：下拉列表里一堆 `V1` `V2` `V3` 看着烦？自动合并成一个系列名，清爽多了
- **历史快照**：每次修改都有记录，改炸了随时回滚到之前的状态
- **快照对比**：两个版本的参数差在哪？一键 diff 看得清清楚楚
- **切换保护**：切预设之前自动备份，手滑切走也不怕丢修改

自动保存与恢复会通过酒馆的预设管理器写入对应预设；历史快照保存在当前浏览器中。分组和别名只改变显示，不改预设名称。重要操作前建议导出历史备份。

## 安装

### 方法一：扩展管理器装（推荐）

1. 打开 SillyTavern → 右上角拼图图标 🧩 →「管理扩展」
2. 输入地址：
   ```
   https://github.com/SillyTavern-Extras/SillyTavern-PresetAutoSave
   ```
3. 点安装 → 刷新页面 → 搞定

### 方法二：Git 克隆

```bash
cd data/<你的用户名>/extensions/third-party
git clone https://github.com/SillyTavern-Extras/SillyTavern-PresetAutoSave
```

刷新页面就行。

### 方法三：下载 ZIP

GitHub 页面 → `Code` → `Download ZIP` → 解压到 `data/<你的用户名>/extensions/third-party/SillyTavern-PresetAutoSave/` → 刷新页面。

> 详细安装说明和问题排查看 [docs/installation.md](docs/installation.md)

## 装好之后

装完刷新页面，你会看到：

- 预设栏右边多了个 🕐 时钟图标 — 点它打开历史面板
- 预设名旁边多了个小圆点 — 显示保存状态（绿色=保存成功，黄色=正在等待保存）
- 预设下拉列表里同系列的版本已经合并了

### 常用操作

| 想干嘛 | 怎么做 |
|--------|--------|
| 回滚到之前的状态 | 🕐 历史面板 → 找到想恢复的快照 → 点恢复 |
| 指定系列用哪个版本 | 🕐 历史面板 → 展开系列 → 在版本卡上点📌 |
| 对比两个快照的差异 | 分别标记为 🅰 和 🅱 → 点「开始对比」 |
| 关掉预设合并功能 | 🕐 历史面板 → 设置 → 预设接管 → 关掉开关 |

> 完整使用说明看 [docs/usage.md](docs/usage.md)

## 设置在哪

所有设置都在 **🕐 历史面板 → 设置 Tab** 里，包括：

- 自动保存开关和防抖延迟
- 历史记录保留条数
- 切换保护开关
- 预设接管开关
- 状态指示器显示
- 等等

默认配置就挺好用的，一般不用改。

## 常见问题

**Q: 预设下拉显示不对了怎么办？**
> 历史面板 → 设置 → 预设接管 → 关掉就行，下拉立刻恢复原状。

**Q: 数据存在哪？**
> 浏览器的 IndexedDB 里。清浏览器数据就没了，建议偶尔用「导出全部」备份一下。

**Q: 会修改我的原始预设文件吗？**
> 会。自动保存、手动保存和恢复会调用酒馆的保存接口。禁用会解除界面接管；删除扩展前应先导出备份，并确认恢复流程完成。读取或写回失败时会保留恢复数据，不把部分完成当作成功。

**Q: 看不到 🕐 按钮？**
> 确认插件已启用。还不行的话按 F12 打开控制台看有没有 `[PAS]` 开头的报错。或者直接在控制台输入 `window.__pas.showHistoryPanel()` 试试。

**Q: 跨设备怎么同步？**
> 设备 A「导出全部」→ 把 JSON 文件拷到设备 B →「导入」选合并模式。

**Q: 导出会泄露 API Key 吗？**
> 不会，敏感信息在保存快照的时候就自动过滤掉了。
