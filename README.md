# SillyTavern Preset Auto Save

> 让你的预设列表干净如新 · 自动备份每次改动 · 永不丢失 · 极致兼容

一个为 SillyTavern 量身打造的 **预设智能管理** 扩展。
它会**接管原生的预设下拉**，把"梦境思客V1-0425 / V2-0426 / V2-0427-3 ..."这样冗长的列表自动合并成 **「梦境思客」** 一行；同时为你的每次修改无声地保留一份历史，让你随时回到任何一个时刻。

---

## ✨ 核心特性

### 🪄 预设接管 —— 让原生列表干净如新

- **自动合并同系列预设**
  把同一个系列的多个版本（`v1.1` / `v1.2` / `v2.0` ...）在原生下拉里折叠成一个"系列名"，不再被一长串重复名字淹没。
- **任你指定每个系列的"默认应用版本"**
  在历史面板二级菜单中，点击图钉图标即可为某个系列指定默认版本。
  之后只要在原生下拉里选这个系列，就会自动应用你设的默认版本（或最新版）。
- **零数据风险**
  接管只发生在 DOM 视觉层 —— 你的预设数据本身**完全不动**。
  随时可以在设置中关闭接管，下拉立即恢复原状。

### 🔄 自动保存 —— 改动不丢一笔

- 修改任意预设字段（输入框/滑块/下拉/开关）后自动保存
- 智能防抖：文本类输入用更长延迟（1.5s），其它操作即时响应
- 滑块松手才保存：避免拖动过程中频繁触发
- 智能去重：内容没变化时跳过保存，不浪费空间
- 切换保护：切到其它预设之前，自动备份当前未保存的修改

### 📜 历史版本管理 —— 永不丢失

- **三级面板**：系列 → 版本 → 历史快照，井然有序
- **快照内容**：每条快照保留完整预设数据 + 触发原因 + 时间戳
- **可命名 / 钉选**：重要节点自定义名字、永不被自动清理
- **可对比**：选两个快照实时高亮 diff
- **可恢复**：一键回到任何一个时间点的状态
- **可导出/导入**：完整备份所有快照到 JSON

### 🛡️ 极致兼容

- 多层降级：`getPresetManager` 缺失时回退到 `window.presetManagers`
- IndexedDB 不可用时自动用 localStorage 兜底
- 严格使用 ESM + 标准 DOM API，回避不兼容的 `Object.hasOwn` / 正则 lookbehind / `structuredClone` 等新特性
- 在 SillyTavern 各版本（1.10.x +）和 Safari/Chrome/Edge/Firefox 全栈兼容

## 📦 安装

### 方法 1：通过扩展管理器（推荐）

1. 打开 SillyTavern
2. 点击扩展面板（右上角拼图图标）→「管理扩展」
3. 在仓库地址输入：
   ```
   https://github.com/SillyTavern-Extras/SillyTavern-PresetAutoSave
   ```
4. 点击安装 → 刷新页面 → 完成 ✓

### 方法 2：手动安装

```bash
cd data/<your-username>/extensions/third-party
git clone https://github.com/SillyTavern-Extras/SillyTavern-PresetAutoSave
```

刷新 SillyTavern 即可。

### ② 历史面板入口

预设栏的最右侧多了一个 🕐 时钟图标，点击 → 历史记录面板。

### ③ 历史面板的"列表" Tab —— 三级管理

```
[v] 梦境思客  · 5 个版本 · 23 条快照            ← 一级（系列）
    [v] V2-0427-3       (默认 ★)               ← 二级（版本）
        ├─ 2025-04-29 14:32  (auto)
        ├─ 2025-04-29 13:11  (manual)
        └─ ...                                  ← 三级（快照）
    [>] V2-0426
    [>] V1-0425
[>] 北棱预设
[>] Izumi
```

- **二级版本卡** 上的图钉按钮：设为该系列的"默认应用版本"
- **二级版本卡** 上的圆勾按钮：直接应用此版本（绕过代表项）
- **三级快照卡**：恢复 / 查看 / 重命名 / 钉选 / 对比 / 删除

### ④ 设为默认应用版本

```
1. 在历史面板二级版本卡中找到你想设为默认的版本
2. 点击图钉图标 📌
3. 该版本被标记为"默认"
4. 之后在原生下拉里选这个系列 → 会自动应用这个版本
```

### ⑤ 关闭接管

不喜欢接管？随时可关：

```
历史面板 → 设置 Tab → 预设接管 → 关闭"接管原生预设下拉"
```

下拉**立即**恢复原状，所有 option 按原顺序插回。

## ⚙️ 详细设置

### 自动保存
| 选项 | 默认值 | 说明 |
|------|--------|------|
| 启用自动保存 | ✅ | 总开关 |
| 通用防抖延迟 | 800ms | 修改后多久触发保存 |
| 文本框防抖延迟 | 1500ms | 编辑文本时使用更长延迟避免频繁保存 |
| 滑块释放保存 | ✅ | 仅在松开滑块时保存（推荐） |
| 跳过未变化的保存 | ✅ | 内容相同则不写入磁盘（推荐） |

### 历史记录
| 选项 | 默认值 | 说明 |
|------|--------|------|
| 每预设保留条数 | 50 | 超出后自动删除最旧的 |
| 合并窗口 | 30s | 此时间内的连续修改合并为一条记录 |
| 存储阈值 | 50 MB | 超过此大小提示清理 |

### 切换保护
| 选项 | 默认值 | 说明 |
|------|--------|------|
| 切换保护 | ✅ | 切换预设前自动备份当前修改 |

### 外观
| 选项 | 默认值 | 说明 |
|------|--------|------|
| 显示状态指示器 | ✅ | 预设名旁的小圆点（绿/黄/灰） |
| 保存时弹出通知 | ❌ | 每次保存显示 Toast |

### 预设分组
| 选项 | 默认值 | 说明 |
|------|--------|------|
| 启用预设系列分组 | ✅ | 把同名不同版本的预设自动归为一个系列 |
| 导入新预设时确认归属 | ✅ | 检测到新预设与现有系列相似时弹窗提示 |
| 默认展开策略 | 仅当前预设所在系列 | 进入面板时哪些系列默认展开 |

### 预设接管 ⭐
| 选项 | 默认值 | 说明 |
|------|--------|------|
| 接管原生预设下拉 | ✅ | 把同系列多个版本合并为系列名 |
| 代表版本策略 | 自动使用最新版本 | 没有为某系列指定默认时的回退策略 |

### 高级
| 选项 | 默认值 | 说明 |
|------|--------|------|
| 调试日志 | ❌ | 在浏览器控制台输出详细日志 |
| 兜底轮询 | ❌ | 仅当事件触发不可靠时启用 |

## 🎯 设计原则

1. **不破坏原生数据** —— 接管只在 DOM 层做"视觉合并"，永远不修改 PresetManager 的预设本身
2. **完全可还原** —— 每个被摘除的 option 都保存了原始 prevSibling 引用，关闭接管后状态恢复 100%
3. **性能优先** —— `content-visibility: auto`、`requestAnimationFrame` 批渲染、Promise.all 并行 IO、原地切换 DOM 而不是重建
4. **用户体验** —— `cubic-bezier(0.16, 1, 0.3, 1)` 自然减速曲线、`prefers-reduced-motion` 适配、移动端响应式
5. **零依赖** —— 不引入任何第三方库（除了 SillyTavern 本就有的 localforage）
